# Deaconia brand assets

Visual identity for the **Deaconia** platform — "Sacred" direction (deep teal + gold).
The mark is a flared Coptic cross set in a ring, echoing the Coptic Orthodox context
of the churches Deaconia serves.

## Palette

| Token        | Hex       | Use                                   |
|--------------|-----------|---------------------------------------|
| Pine Teal    | `#114B4F` | Primary brand ground, icon background |
| Deep Teal    | `#0E4A4E` | Wordmark on light, dark titles        |
| Icon Gold    | `#D4AF37` | The mark, accents (matches `#C9A227`) |
| Mist         | `#EEF2EF` | Light-theme background                |
| Off-white    | `#F5EFE3` | Reversed mark / wordmark on teal      |
| Ink (mono)   | `#082926` | Black-and-white mark                  |

## Files

| File                          | What it is                                        |
|-------------------------------|---------------------------------------------------|
| `deaconia-mark.svg`           | Primary mark, gold on transparent                 |
| `deaconia-mark-mono.svg`      | Black-and-white (single-ink) mark                 |
| `deaconia-mark-reversed.svg`  | Off-white mark for dark/teal backgrounds          |
| `deaconia-icon.svg`           | App icon — gold mark on a teal rounded square      |
| `deaconia-logo-color.svg`     | Horizontal lockup: mark + "Deaconia" wordmark      |
| `deaconia-logo-reversed.svg`  | Horizontal lockup on a teal ground                 |
| `../../favicon.svg`           | Browser favicon (teal square + gold cross)         |

## Note on the wordmark

The wordmark uses a system serif (`Georgia`) as a placeholder so the SVGs render
everywhere without an embedded font. For final print/production, convert the
"Deaconia" text to outlines (or embed the chosen serif) so it is font-independent.
